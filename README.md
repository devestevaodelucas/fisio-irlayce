# 🩺 Dra. Irlayce Ribeiro — Site Institucional

Landing page profissional desenvolvida para a fisioterapeuta Dra. Irlayce Ribeiro, especializada em atendimento domiciliar em Recife - PE.

## 🌐 Acesse o site

[clique aqui para acessar](https://devestevaodelucas.github.io/fisio-irlayce)

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Media Queries, animações)
- JavaScript (integração com WhatsApp)
- Google Fonts (Cormorant Garamond + Montserrat)
- GitHub Pages (hospedagem)

## ⚙️ Funcionalidades

- Layout responsivo para celular e desktop
- Animações de hover no logo e menu
- Formulário integrado ao WhatsApp com mensagem personalizada
- Scroll suave entre seções
- Clique no logo leva ao topo da página
- SEO básico com meta description
